# 🎓 Student Management System

A simple **Java console application** for managing student records using **OOP, ArrayList, and Scanner**.

### Features

* Add student records
* Store ID, name, age, and department
* Menu-driven interface

### Technologies

**Java | OOP | ArrayList | Scanner**
